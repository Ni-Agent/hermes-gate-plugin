# Local release reference history

The public beta version is `0.1.0-beta.1`. Before public publication, the local
prototype tag of that name identified commit `dd6add636e3ae14eede243b7c1b609a74ee5fc37`.
Its original reference is preserved as `legacy/v0.1.0-beta.1`. The public beta tag
is assigned to the current release candidate. Earlier prototype beta2/beta3 tags
remain available for upgrade regression checks. The provisional unpublished
`v1.0.0-beta.1` candidate is retained as `legacy/v1.0.0-beta.1`.

Existing Git installations update by source revision through Hermes's native
updater. Regression checks cover updating both the original prototype and beta3
to the public beta while preserving credentials and user files. The older
prototype version numbers do not describe public release chronology.
